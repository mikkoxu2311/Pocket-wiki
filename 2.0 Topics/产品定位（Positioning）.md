# 产品定位（Positioning）

Positioning 为目标客户建立一个理解框架：产品属于什么类别、替代什么、为什么在特定情境下更有价值。

## 建议顺序

1. 找到真实 competitive alternatives，包括 status quo。
2. 明确相对于替代方案的独特能力。
3. 把能力翻译为客户价值。
4. 找到最在意这些价值的 best-fit customers。
5. 选择能让价值容易理解的市场类别。
