# Jobs to Be Done（JTBD）

JTBD 把市场理解为人在特定情境下为取得 progress 而改变行为的过程。

## 核心模型

- Struggling moment 产生 demand。
- 对现状的不满和新方案吸引力推动改变。
- 对新方案的焦虑与现状习惯阻碍改变。
- 真正的竞争者包括用户当前用来取得同一进展的所有方式，不只是同类软件。

## 与 Positioning 的连接

[[产品定位（Positioning）]] 从客户的 competitive alternatives 开始；JTBD 提供了发现这些替代方案的需求侧视角。
