# 产品驱动增长（PLG）

PLG 不是“没有销售”，而是产品在 acquisition、activation、monetization 或 retention 中承担可识别的增长职责。

## 综合结论

- 产品承担的增长环节越多，越需要增长产品能力。
- Sales-led 公司可以晚些建立独立 growth team，但不等于不需要产品参与增长。
- PLG 的前提仍是 [[产品市场匹配（PMF）]]、清晰 activation 与足够数据。
- [[Freemium、Trial 与 Reverse Trial]] 是分发与变现设计，不是 PLG 的定义本身。
