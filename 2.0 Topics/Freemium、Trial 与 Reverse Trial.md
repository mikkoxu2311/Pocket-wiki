# Freemium、Trial 与 Reverse Trial

## 三种模式

- **Freemium**：长期保留受限免费价值，适合重视广泛使用、品牌曝光或网络效应的产品。
- **Free trial**：在有限时间展示付费价值，适合价值可在试用期内充分体验的产品。
- **Reverse trial**：先开放完整功能，结束后回落到 free plan。

## 决策问题

1. 用户需要多久才能感知核心价值？
2. 免费用户是否会给付费业务带来分发或网络价值？
3. 边际服务成本是否允许大量免费用户？
4. 付费功能能否在试用期形成清晰 aha moment？
5. 模式是否与 [[支付意愿（WTP）]] 和定位一致？
