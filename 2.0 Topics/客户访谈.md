# 客户访谈

## 目标

理解真实行为、情境和决策过程，而不是让用户替团队设计产品。

## 做法

1. 询问最近一次具体事件，不问泛泛偏好。
2. 重建时间线：触发点、搜索、比较、焦虑、决定与结果。
3. 使用“再举一个例子”“当时发生了什么”，少用连续抽象的“为什么”。
4. 复述你的理解，让受访者纠正因果链。
5. 将机会放入 [[机会解决方案树（OST）]]，不要直接把每句话变成功能。
