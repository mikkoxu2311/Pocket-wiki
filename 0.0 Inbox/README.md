# 0.0 Inbox｜把原始材料放在这里

把要导入的 `.md`、`.txt`、PDF 或其他 Agent 可读取的文字材料放进本目录。然后用 Codex 打开仓库根目录，直接说：“帮我处理 Inbox 里最新加入的材料。”仓库自带的 `llm-wiki-ingest` Skill 会完成导入。

规则：

- Agent 只能读取这里的文件，不能改写、移动、重命名或删除；
- 可以一次加入一份或多份材料；Agent 会逐份查重、处理并统一 QA；
- 尽量保留标题、作者、日期、版本、URL、页码或时间戳；
- 默认 `.gitignore` 不追踪本目录中的个人材料，避免误公开。需要版本管理时请自行调整规则。
